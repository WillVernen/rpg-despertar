# O Despertar

`O Despertar` e um RPG de texto em desenvolvimento, criado em Python.

## Estado atual

A versao inicial apresenta o menu principal e a introducao narrativa, na qual o personagem desperta sem memoria e encontra um bilhete misterioso.

## Como executar

1. Tenha o Python 3 instalado.
2. Na pasta do projeto, execute:

```bash
python main.py
```

O jogo sera evoluido por etapas, adicionando combate, personagens, escolhas, sistema de salvamento e novas partes da historia.
